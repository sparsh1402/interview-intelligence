# Raw experience (verbatim)

🚀 Interview Experience – Mastercard (SDE 2, Full Stack Developer)

Recently, I had the opportunity to interview with Mastercard for SDE2 profile in Full Stack Development (Angular + Spring Boot backend). It was a Super Day format with three back-to-back rapid rounds (45 minutes each).

🔹 Round 1 – Core Java & Fundamentals

The first round was more theory-oriented, covering:
- Java basics – memory management, string pool, Java 8 features.
- Multi-threading vs. multi-tasking concepts.
- Some discussion on executor services and thread pools.
- SOLID principles and overall object-oriented design understanding.

This round was moderate, focused on validating fundamental concepts.

⸻

🔹 Round 2 – Deep Dive into Spring + Concurrency

The second round was conducted by a senior developer and was very fast-paced (new question almost every 10 seconds).

Key areas:
- Spring Boot – annotations, differences in Spring vs Spring Boot 3, Spring Security, JPA/Hibernate.
- Dependency Injection – @Autowired vs constructor injection.
- Executor Services – detailed features, thread pools, and usage.
- Java Features – old vs new (streams, lambdas, etc.), memory handling, garbage collection.
- Concurrency & Locks – different types of locks, scenarios on where/how to apply them.
- Scenario-based problems – designing where to place locks in multi-threaded situations.
- Project Discussion – deep dive into my work, with focus on performance improvements (e.g., justifying why I reported a "30% improvement in query performance," how that metric was calculated, and why not a different percentage).
- Design Patterns – discussion across different patterns with examples.

This was intense and tested both depth and breadth of my knowledge.

⸻

🔹 Round 3 – Managerial + DSA

The final round was a mix of problem-solving and conceptual discussions:
- DSA problem – HashMap + sorting (moderate/easy level).
- Executor Services & Thread Pools – detailed discussion again:
  - How thread pools are created.
  - Whether threads "actually die" in a system.
  - Lifecycle and management of threads.
- Multi-threading concepts were revisited in detail.

⸻

💡 Key Takeaways

The interview process was well-structured yet rapid, heavily focusing on:
- Java 8 and beyond
- Spring Boot (core + advanced)
- Multi-threading, concurrency, and executor services
- System design principles & patterns
- Project impact validation (quantifying improvements)

Overall, I was Rejected , may be not performed well in Round 2, but it was a great learning experience and a reminder of how important multi-threading + Spring ecosystem expertise is for backend-heavy full stack roles.
